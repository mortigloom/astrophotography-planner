# Astrophotography Planner

An app concept for planning night-sky photography and helping photographers prepare for a session. This repository is a public overview of the project; the app is in development.

## Planned features

- Explore star charts to plan what to photograph.
- Track lunar events and identify nights with little or no moonlight.
- Find dark-sky conditions and recommended astrophotography locations.
- Follow guidance for setting up an equatorial mount.

## Current focus

Research the astronomy and location data needed for reliable planning, design the user workflow, and build and test the app.
